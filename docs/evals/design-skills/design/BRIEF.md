# Design-path eval — brief

Design the **Dividends** screen for StockerPro, a dark-theme retail portfolio app.

Users open this screen to check the projected annual dividend income from their holdings. The
screen must let them:

- see the holdings and each one's annual income and yield,
- remove a holding,
- refresh prices from the network,
- filter the time range,
- control whether the portfolio is shared by link,
- understand and recover from a failed refresh.

Constraints: it is a React/Next.js app using shadcn/ui, Tailwind, Lucide and the existing dark
tokens. Produce throwaway HTML mockups only — no application source.

This is an **evaluation run**, not an adoption run. No direction will be adopted; the outputs
are scored against a rubric. Produce 2–3 genuinely different variants, render each, and write
`DECISION-SHEET.md`. Name the direction you would recommend *for scoring only*; do not present
it as approved, and do not ask for approval — stop after the decision sheet.
