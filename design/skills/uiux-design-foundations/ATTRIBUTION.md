# Attribution — uiux-design-foundations

## Source material
- Book: *From Zero to UI/UX Hero!* by Conrad Böhnke, published by UI Rocket, 2024.
- The user supplied the PDF of the book on 2026-10-20 and asked for it to be turned into a design skills package.
- The book is in two parts: Part 1 covers UI design (colour, typography, spacing and layout, icons, buttons, white space); Part 2 covers UX design (research and personas, UX laws, information architecture, developer collaboration, concept design, and advanced theory). Page citations in `references/` are PDF page numbers of that supplied copy.

## What is original here
- Every summary, rule, and checklist in this skill is a **paraphrase written fresh** from study notes on the book. No body text from the book is reproduced; only chapter headings, named laws and principles (Miller's Law, Fitts's Law, the Action Cycle, and similar short technical terms), and standard values the book teaches (the 8pt system, the 60-30-10 rule, the WCAG 4.5:1 contrast ratio) are carried over, because a skill about the foundations has to name them.
- All code in `references/code-examples.md` is **original CSS written for this skill** to implement the rules (spacing scale, type scale, grid, button states). It is not copied from the book, which is a principles text and contains no code to copy.
- Several laws and theories in the book originate with other researchers (George Miller, Jakob Nielsen, Paul Fitts, Don Norman, Mihaly Csikszentmihalyi, Jay Appleton, Rudolf Arnheim, John Sweller). The references name those origins where the book does.

## Extraction method and limits
- The book PDF is image-only, so it was read by rendering pages to images. Six note files covering pages 1–138 were produced first, and the references in this skill were distilled from those notes, not re-derived from page images.
- Values and lists were cross-checked against the book's own quiz recap (for example the 8-point system, 24px default icon size, 16px base text size).
