# Checklist — G6 Browser/HMI Verification

Gate: `G6` · Layer: **existing** (§15.1) · Certifier: **Verifier**
Applies only when the feature has a UI surface (`config.yml` `depths.<L>.ui_gates_conditional`).
`CONDITIONAL`: permitted with a specific, owned, dated condition. Forbidden anywhere in an L4 feature.

> §15.1: existing gate. The lifecycle supplies surface verification against `AC-*`. The existing definition governs enforcement.

## 0. Pre-checklist blocking checks

- [ ] Author and certifier identity blocks complete; identity rule satisfied (§9.1.1).
- [ ] The certifier is not the author of the UI under test.
- [ ] Applicability confirmed. If the feature has no UI surface, record `NOT_APPLICABLE` with a reason.
- [ ] Target surface identified from `config.yml` `test_surfaces`.

## 1. Rendered verification on the target surface

- [ ] Every UI `AC-*` verified on the **target** surface, not only on a host mock.
- [ ] Evidence carries immutable references per §9.1.2, including the surface id.
- [ ] Screenshots or captures committed as result files with checksums.

## 2. Behaviour under real conditions

- [ ] Verified at the target resolution and density.
- [ ] Verified under the supported input methods for that surface.
- [ ] Loading, empty, error and unavailable states each rendered and verified.
- [ ] Latency `NFR-*` measured at the surface boundary, with the measured value recorded.

## 3. Audio Settings instantiation

- [ ] Setting change on the HMI produces the **audible** outcome on a surface with a real audio path — `bench_hu` or `vehicle`. A state readback is not sufficient evidence here.
- [ ] Control scope verified on-surface: a per-seat change is observed not to alter another seat.
- [ ] `shared_vehicle` override and limit indications verified with two occupants represented.
- [ ] Focus and ducking transitions verified as rendered: what the user sees while another source holds focus.
- [ ] Mute and unmute verified for both audible outcome and displayed state.
- [ ] Role-based visibility verified for driver, co_pilot, normal, kids and guest.
- [ ] Driving-context restriction verified in the restricted state, not only the permitted one.
