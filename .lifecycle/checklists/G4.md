# Checklist — G4 Executable Validation

Gate: `G4` · Layer: **existing** (§15.1) · Certifier: **Verifier**
Governed by: spec §9.2, §9.1.2, §10.
`CONDITIONAL`: permitted with a specific, owned, dated condition. Forbidden anywhere in an L4 feature.

> §15.1: existing gate. The lifecycle supplies F13 evidence with immutable references. The existing definition governs enforcement.

## 0. Pre-checklist blocking checks

- [ ] Author and certifier identity blocks complete; identity rule satisfied (§9.1.1).
- [ ] The certifier is not the Implementer who authored the code or tests.
- [ ] `config.yml` `commands` is bound. **If unbound, this gate cannot be certified** — record that rather than substituting an ad hoc command.

## 1. Immutable evidence references (§9.1.2)

Every evidence item, not just a summary count:

- [ ] `claim`
- [ ] `command` — exactly as run
- [ ] `commit`
- [ ] `environment`
- [ ] `timestamp`
- [ ] `result_file` — committed, under `features/<ID>/evidence/F13-unit/`
- [ ] `checksum` — sha256
- [ ] An assertion with no result file FAILS before any item below.

## 2. Executable checks

- [ ] Build passes, with captured output.
- [ ] Unit tests pass, with captured output.
- [ ] Static analysis clean, with captured output.
- [ ] Selected coverage thresholds from `F5-test-analysis.md` met, with captured output.

## 3. Test integrity

- [ ] No test weakened, retuned, skipped, disabled or deleted to make the build pass.
- [ ] Skipped or disabled tests, if any, are enumerated with a reason and an owner.
- [ ] Per unit: positive, negative, boundary and error-handling cases present.
- [ ] Error paths are **exercised**, not merely reachable.

## 4. Trace integrity

- [ ] `trace.yml` was updated in the same change as the code.
- [ ] Every changed file maps to an `IMP-*` and an `AC-*`. Zero `orphan code` under §8.4.
- [ ] Every `IMP-*` lists its tests.

## 5. Audio Settings instantiation

- [ ] Units reaching the HAL, VACS or Audio Hub seams assert the outbound call **and its arguments**, not only a local state write.
- [ ] State-readback assertions are labelled as such and are not counted as audible-outcome evidence.
- [ ] Audible-outcome verification is deferred to F14 or F15 on `bench_hu` or `vehicle`, and that deferral is recorded here rather than left implicit.
- [ ] Negative cases cover HAL or IPC unavailability at the seam, with the declared error surfaced.
- [ ] Boundary cases cover the setting's minimum and maximum, and the maximum supported setting count where persistence is involved.
- [ ] Per-seat units assert isolation: writing one seat's value leaves other seats unchanged.
